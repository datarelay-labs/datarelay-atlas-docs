# Engineering System

[Data Relay Labs Engineering System](https://github.com/datarelay-labs/engineering-system) is the canonical, tool-neutral methodology for designing, building, testing, releasing, operating, and evolving software with AI assistance.

Atlas does not redefine that methodology.

Atlas can:
- discover project adoption state
- read project-local engineering metadata
- visualize lifecycle state
- connect evidence and knowledge
- expose the relevant context to AI agents
- identify unknown/stale/gapped engineering context

The Engineering System remains canonical even if Atlas is unavailable.
