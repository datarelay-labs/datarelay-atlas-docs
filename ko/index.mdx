# DataRelay Atlas

**Map your engineering. Connect your AI.**

DataRelay Atlas는 여러 소프트웨어 프로젝트의 Engineering 방법론, 프로젝트/라이프사이클 상태, 지속 가능한 지식, AI Context를 연결합니다.

사람과 AI가 과거 대화를 재생하지 않고도 동일한 최신 Engineering Context를 사용하도록 하는 것이 목적이며, Wiki가 canonical source와 경쟁하지 않도록 설계합니다.

## Atlas가 연결하는 것

- **Methodology** — Data Relay Labs Engineering System
- **Projects** — Repository, Product, Architecture, Specification, ADR
- **Lifecycle** — 개발, 검증, Review, Release, Operations
- **Knowledge** — 프로젝트별/프로젝트 간 검색 가능한 Engineering Context
- **AI Context** — Cursor, ChatGPT 및 MCP 기반 AI용 scoped context

## Atlas가 대체하지 않는 것

Atlas는 GitHub, CI/CD, Issue Tracker, Coding Agent, 범용 협업 도구를 대체하려는 제품이 아닙니다. 이들 시스템의 Engineering Evidence를 관찰하고 연결합니다.

## 현재 단계

현재 초기 제품 정의 및 Architecture bootstrap 단계입니다. 첫 구현 단계에서는 Project Registration, Canonical Source Sync, Provenance, Retrieval, AI/MCP Access에 집중합니다.
