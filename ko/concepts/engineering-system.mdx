# Engineering System

[Data Relay Labs Engineering System](https://github.com/datarelay-labs/engineering-system)은 AI-assisted software의 Design, Development, Test, Release, Operations, Evolution을 위한 canonical tool-neutral methodology입니다.

Atlas는 이 방법론을 다시 정의하지 않습니다.

Atlas는 다음을 수행할 수 있습니다.

- Project Adoption 상태 확인
- Project-local Engineering Metadata 읽기
- Lifecycle State 시각화
- Evidence와 Knowledge 연결
- AI Agent에 필요한 Context 제공
- Unknown/Stale/Gap 상태 식별

Atlas를 사용할 수 없는 상황에서도 Engineering System 자체는 canonical로 유지됩니다.
