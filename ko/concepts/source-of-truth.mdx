# Source of Truth

Atlas는 Engineering System의 authority model을 따릅니다.

1. 실행 가능한 Code/Config/Schema는 runtime truth입니다.
2. 승인된 Product/Specification Artifact는 intended behavior를 정의합니다.
3. Repository Engineering Metadata는 lifecycle contract를 정의합니다.
4. ADR은 장기적인 Architecture Decision을 기록합니다.
5. Runbook/RCA는 운영 절차와 Incident Learning을 기록합니다.
6. Atlas Knowledge는 Navigation, Search, Synthesis, AI Retrieval을 위한 derived layer입니다.

Atlas의 Derived Content는 가능한 경우 Source Provenance를 보존해야 하며 Canonical Repository State를 조용히 덮어쓰면 안 됩니다.

둘이 충돌하면 **Canonical Git/GitHub Content가 우선**합니다.
